# pokemon-api
Used to search through pokemon and find their height, weight, ID, and name. The requests library is required. From there, you can run the program in VSCode or any other text editor. This program can be used to easily find information on a Pokemon for any situation.
# Install dependencies:
`pip install requests`
How to use:
Type in any real pokemon into the input. The height, weight, ID, and name will then appear!
